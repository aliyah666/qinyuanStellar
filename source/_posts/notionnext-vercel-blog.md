以下是作者 [@tangly](https://github.com/tangly1024) 的原文，我也十分认同作者的理念，这也是我选择它的原因。

> 按我的个人习惯来说，之所以选用这种替代方案，取决于三个痛点：
>
> - **写作**：用 Notion 写笔记的方式来写文章更舒适，也长远可持续。用公众号编辑器、WordPress 后台、第三方博客平台写文章，太难养成习惯；用自己的笔记本写东西才不费力，用着舒服，才可能做得长久、做得好。
> - **维护**：服务器的安全、升级，数据库的备份、维护，都要耗费精力；更可怕的是"折腾服务器"的成就感会上瘾，让你不断从搭建中获得甜头，沉迷于折腾软件技术。
> - **费用**：服务器、域名——我只想发布博客文字，有必要花那么多钱租一年的服务器吗？

这里面 Vercel 替代了服务器，Notion 充当数据库，NotionNext 则是核心代码。下图就是我部署好的博客，目前正在持续优化中。

## 开始之前，先看效果

开始部署之前，建议先去 NotionNext 的[预览站点](https://preview.tangly1024.com/)逛一圈，在左下角可以切换主题，有 25 个主题可选。部署好之后再修改主题，后续想换也能随时换，我选的是 Next 主题。

## 跟着教程走，但有个提醒

本来我想一步步写部署过程，但作者的教程已经写得足够详细，没必要重复造轮子。我的博客就是照着[教程](https://notionnext.tangly1024.com/user-guide/start-here)一步步操作下来的。

不过要提醒一句：教程里的页面截图是两三年前的了，平台这几年更新不少，现在看到的界面和图里会有差异。这里强烈推荐我之前文章里提到的 [AI 助手](https://app.notion.com/p/AI-AI-399bea0bcb8e808c8b70f53cd376451e?pvs=21)，下载一个，遇到拿不准的地方直接截图问它，有了它能省很多脑力，0 基础也能搞定。

## 几个需要注意的点

这里补充几个细节，能避免一些不必要的麻烦：

1. 网络环境：需要能稳定访问 GitHub 和 Vercel，否则这两个网站可能打不开。
2. 邮箱：准备一个国际邮箱（Gmail、Outlook 等）用来注册 GitHub 和 Vercel——国内邮箱注册 Vercel 会报错。
3. 登录顺序：先注册好 GitHub，接着注册 Vercel 时选「用 GitHub 登录」，两个网站先别关，都保持登录状态，待会会用到。
4. 页面 ID：浏览器地址栏里 `/` 和 `?` 之间的那串字符，就是你的 32 位页面 ID。复制下来顺手发给 AI 帮确认下是不是 32 位——主要是太长了，我懒得数。

后面照着作者的教程去操作即可。部署好确认能正常访问之后，接下来就是买域名。

## 域名

域名是这套方案里唯一需要花钱的地方。原因是 Vercel 自带的域名在大陆大概率无法访问，所以得自己买一个。我的域名 qinyuan.me 是在 [Namesilo](https://www.namesilo.com/pricing) 上买的，首年 9.9 刀，续费 19.9 刀。域名丰俭由人，从十块到几百块都有，看你喜欢。
