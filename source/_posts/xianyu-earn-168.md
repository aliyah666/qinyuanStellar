{% box color:cyan %}把自己30元买来的一本电子书挂上闲鱼，3个月成交 14 单、累计 168 元。金额不大，却跑通了一次完整的"痛点 → 方案 → 成交"验证。{% endbox %}

## 一、为了一本电子书，我花了30元开会员

事情是这样的。我之前刷到某个读书博主，然后被安利了一本书。这本书在国内还没有出版，我找遍了闲鱼、PDD、当当网、二手书平台都没有，让人代找也没找到；唯一有货的两个渠道，一个淘宝进口原版要 80 多块，一个电子版要 50 块，都被价格劝退。

后面过了一段时间，我在网上某个平台搜到了这本书的网盘资源——可能也是刚上传到网盘不久，因为在这之前我也搜索过，并没有找到。我为了使用这个平台，花 {% mark 30 元 color:orange %} 开了他们的永久会员，不出意外，目前已经无法访问了。

## 二、把它挂上闲鱼，3 个月成交 168 元

在找到了之后我就在想：是否有人也像我这样，为了找这本书却一直找不到？我觉得有这个可能。然后我就把这本书挂到闲鱼，大概一个月的时间，竟然卖出去了两单，把开会员的钱回本了。

理由其实很简单：在找书的过程中，我发现了一个真实存在的需求——如果一本书还没有在国内出版，对一般人来说想要看这本书，确实会存在一定难度：

- 缺乏搜索技巧
- 网络原因，无法使用 Google，导致不一定能检索到

正巧我在找书的时候发现了一个网站，里面有不少大陆还没有出版的电子书资源。我觉得应该有部分书籍是有人想看而找不到的，于是抱着这个想法，陆陆续续在三个月内，累计在闲鱼上架了 75 部电子版资源，成交 {% mark 14 单 color:green %}，平均售价 12 元一本，总成交额 {% mark 168 元 color:red %}。

事实证明，这个需求是确实存在的。在这个过程中，也有买家让我找书，但是由于比较冷门或者网络上没有这个资源，以及个人技术水平有限，最后没有找到。

{% image /images/xianyu-deal-records.jpg "闲鱼成交记录" %}

成交量不大的原因，我也复盘了一下，主要有 3 点：

{% box color:yellow %}

- 供需不匹配，提供的资源不一定是别人需要的，只命中了一小部分
- 资源数不够多
- 12 元的定价可能偏贵

{% endbox %}

回过头看，在找书卖书这件事里，我从一个自己的找书需求出发，拓展到别人可能也存在同样的需求，再通过闲鱼平台上架进行 MVP 验证；在验证可行之后，我拓展到了其他书籍，上架更多的电子资源，到成交 168 元。金额不大，但是却是一次很好的痛点验证——真正把一个痛点转化成了实实在在的收益。

## 三、19.9 的课和 19.9 的订阅，为什么都没卖出去？

这期间，我基于这个电子书的需求，花了 2 天制作了一个简单的电子书检索课，定价 19.9 元，在小红书进行推广。但是发现小红书十分卷，很多一两块钱的代找书籍，甚至还有不少免费找书——我猜是为了通过网盘转存拉新赚取收益，还有部分热心网友免费帮忙找书（由衷地为好心人点赞）。最后这个小课，我一份都没卖出去。

事后我反思，为何难以成交？原因之一是：买课还需要自己花时间去学习查找，对部分人来说远不如"买了就走"来得实在；并且也不一定经常有这个需求，花钱学习自己动手未必更有性价比。

于是我就尝试订阅制：19.9 元包任意 5 本电子书（找不到不算，一年内有效）。我在闲鱼单本就卖 12 元了，订阅制算下来 19.9 元 5 本，对比之下单价很低，性价比很 OK。我的最终目的是锁定用户，添加微信转到私域，作为长期流量——反正找书的成本对我来说不高。

接着我在闲鱼成交的客户里，向五个客户推荐了我的包年订阅，结果很离谱：

{% box color:red %}0 成交，4 个已读不回，1 个说"好的，我考虑一下"，然后就没有然后了。{% endbox %}

基于这个结果，我认为多数人的心理还是：单纯花钱买一本电子书，不会考虑花额外的钱去买课或者包年的服务。

## 四、4 条启发 + 关于定价的思考

这个案例里，有哪些启发？我整理了 4 点：

- {% checkbox checked:true color:green 多感受多思考：自己的痛点，可能也是别人的痛点。 %}
- {% checkbox checked:true color:green 低成本解决 + 平台分发：如果能低成本地解决这个痛点，再通过某个平台把解决方案卖出去，就有利可图。 %}
- {% checkbox checked:true color:green 放大受众：如何让更多有这个痛点的人看到我们的解决方案，达成更多的销售。 %}
- {% checkbox checked:true color:green 私域转化：尽量把一次成交，变成客户留存，锁定长期。 %}

关于定价，因为这类资源有一定的稀缺性，并且需求的人偏小众，来的都是通过某个渠道被安利到，然后来闲鱼搜索找书，流量比较精准，所以我定价 12 元一本（闲鱼上一般的电子书代找基本是 5 元左右）。

基于这点，我认为小众赛道能带来更大的利润空间，我也倾向于这个方向——能有更大的话语权和定价权，不用在红海里和竞争对手互卷，靠量大挣辛苦钱。相对应的是，小众赛道受众较小，成交量会比较小。
